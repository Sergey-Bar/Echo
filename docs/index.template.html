Hours of simulation.
Now seconds.

Vehicles drive through a city and their noise spreads along the streets, never through buildings. Detectors fire when the noise they hear adds up to a threshold. The original simulator rebuilt the whole noise map on every frame. Echo doesn't.

Listen where it matters.

Two observations remove almost all of the work: only detector cells need an answer, and a vehicle's noise changes only when it moves.

  1. Step 1

    Listen from the detectors.

    One distance search from each detector, out to the loudest vehicle's reach. Street distance is the same both ways, so the numbers match the simulator's exactly.

  2. Step 2

    Turn routes into segments.

    Each vehicle becomes "on this cell from frame a to frame b". A looping vehicle repeats its lap, so Echo builds one lap and shifts copies in time.

  3. Step 3

    Add up changes, not frames.

    Noise is added when a vehicle arrives near a detector and subtracted when it leaves. One cumulative sum gives every detector's exact noise on every frame.

The same route. Every time.

When two paths are equally short, the simulator's queue picks one in a set order. That order always gives the alphabetically first shortest path, reading moves as up, down, left, right. Echo measures distances from the goal once and walks straight there.

Fast is easy.
Exact is the point.

Every change had to pass all of these before it was kept.

  • Reference cities

    Every example city gives a log identical to the original's, and frame-by-frame snapshots match on the small city.

  • 300 random cities

    Built to hit edge cases: walled-off regions, vehicles louder than the map, parked vehicles, waits, loops, runs cut short, thresholds from trivial to unreachable.

  • Broken on purpose

    Changing "at least the threshold" to "above the threshold" makes the tests fail. They also caught a real bug during development.

  • At the limits

    Every limit at once, on one core with a hard 4 GB cap: 169 s and 277 s, under 1 GB of memory, inside the 10-minute budget.

Try it yourself.

Python 3.12 with numpy and pyyaml. The command line is the same as the original simulator's.

# install
pip install -r requirements.txt

# run the demo city: writes log.json
python -m citynoise run examples/demo.yaml

# make your own city
python tools/make_scenario.py examples/mine --vehicles 20 --detectors 500

# prove it matches the original
python -m pytest tests
